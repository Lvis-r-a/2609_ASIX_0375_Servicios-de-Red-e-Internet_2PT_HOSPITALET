# 🌐 Práctica: Análisis y Resolución del Sistema DNS

Este repositorio contiene la entrega de la práctica correspondiente al módulo **0375 Servicios de Red** del Ciclo Formativo **ASIX**. 

El objetivo principal es el despliegue, configuración y verificación de un servidor DNS funcional en un entorno de red lacio.

---

## 📂 Estructura de la Entrega en esta Carpeta

* 📁 **`image capture/`**: Colección de capturas de pantalla que sirven como evidencia técnica de la instalación, zonas lógicas y pruebas de diagnóstico del cliente al servidor.
* 📄 **`Información DNS.pdf`**: Documento técnico oficial que desarrolla la práctica a nivel teórico y procedimental.

---

## 📋 Contenido Desarrollado en el Informe Técnico

El documento PDF adjunto incluye los siguientes apartados requeridos para la evaluación:

1. **Introducción:** Respuestas teóricas sobre el funcionamiento esencial del DNS, su estructura jerárquica, diferencias entre servidores iterativos y recursivos, registros de recursos (RR) esenciales y mecanismos de mitigación de vulnerabilidades.
2. **Características de Hardware y S.O.:** Especificaciones de la Máquina Virtual utilizando Debian y herramientas del sistema.
3. **Desarrollo:** Manual de usuario paso a paso detallando los aspectos clave del despliegue del servicio DNS.
4. **Análisis de Incidencias Técnicas:** Errores detectados durante la configuración y sus respectivas soluciones aplicadas.
5. **Conclusiones:** Balance técnico sobre el aprendizaje y la implementación del servicio.

---

## 🛠️ Tecnologías y Enlaces de Referencia

La práctica se ha construido utilizando los siguientes estándares de la industria recomendados:
* **Servidor DNS:** [Bind9 (Internet Systems Consortium)](https://isc.org)
* **Configuración de Red:** [NetPlan](https://netplan.io) para la gestión de IPs en el sistema
* **Guía de Despliegue:** Documentación base de [Punkymo GitBook](https://gitbook.io)
* **Herramientas de Red:** `nslookup`, `dig`, `ping`
