Este repositorio contiene la resolución práctica de la actividad de Servicios de Red sobre el sistema de nombres de dominio (DNS).

## 📄 Contenido de la carpeta
* **`Información DNS.pdf`**: Documento principal con las respuestas teóricas y el desarrollo de la actividad.
* **📂 `image capture/`**: Carpeta que contiene las capturas de pantalla de las comprobaciones y configuraciones realizadas.

## ⚙️ Tecnologías y Herramientas utilizadas
* Sistema Operativo: Linux Ubuntu Server / Windows Server
* Herramientas de diagnóstico: `nslookup`, `dig`, `ping`
* Servidor DNS: Bind9 (si aplica)

## 🚀 Comprobaciones realizadas
En la carpeta de capturas se incluyen evidencias de los siguientes apartados:
1. Resolución directa e inversa del dominio.
2. Configuración de las zonas lógicas.
3. Pruebas de funcionamiento del cliente hacia el servidor.
